# Security Policy

## Supported versions

The `main` branch is supported.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability in AegisTrace. Instead, contact the repository owner privately through the GitHub profile associated with the repository and include:

- A concise description and impact
- Affected file and revision
- Reproduction steps or a safe proof of concept
- Any proposed mitigation

We will acknowledge the report, investigate it, and coordinate a fix and disclosure timeline with you.
