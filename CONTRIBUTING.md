# Contributing to AegisTrace

Thank you for helping make AI-assisted security review more rigorous.

## Good contributions

- Clearer instructions that reduce ambiguous agent behavior
- Stronger validation, reachability, or deduplication guidance
- Concrete examples of safe local verification
- Corrections to terminology, structure, or Markdown rendering

## Before opening a pull request

1. Keep changes focused and explain the problem they solve.
2. Preserve the evidence-first, non-destructive philosophy.
3. Update an example when a prompt change affects expected output.
4. Check Markdown links and rendering locally.

Do not include real secrets, private customer data, exploit payloads targeting third parties, or findings from systems you are not authorized to discuss. Security-sensitive reports about AegisTrace itself belong in the process described in [SECURITY.md](SECURITY.md).
